다른 기기 연결

휴대폰 카메라로 QR을 찍거나, 아래 링크를 다른 기기 브라우저에서 열면 토큰 입력 없이 연결됩니다. 링크에 토큰이 들어 있으니 다른 사람에게 보내지 마세요.

토큰 만드는 법 (처음 한 번)

  1. GitHub에서 새 토큰 만들기 (Fine-grained) 열기
  2. Token name: translator, Expiration: 1년 등 원하는 기간
  3. Repository access: Only select repositories → translator-data
  4. Permissions → Repository permissions → Contents: Read and write
  5. Generate token → 나온 토큰을 위 칸에 붙여넣기

이 토큰은 translator-data 저장소 하나만 읽고 쓸 수 있습니다. 토큰은 이 기기 브라우저에만 저장되고 GitHub(api.github.com)로만 전송됩니다. 공용 PC에서는 쓰고 나서 [연결 해제]를 누르세요.
