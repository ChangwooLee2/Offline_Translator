오프라인 번역기

한국어 ↔ 영어. PC Chrome에서는 내장 번역 모델로 기기 안에서만 번역하고, 휴대폰에서는 온라인 번역을 씁니다. 이력과 단어장은 GitHub로 모든 기기에서 공유됩니다.

번역 칸 옆 표시로 구분됩니다: 기기 내 / 온라인. 온라인 번역은 기기마다 처음 한 번 확인 후에만 켜집니다. 회사 기밀 문장은 PC Chrome에서 '기기 내' 표시를 확인하고 번역하세요.

휴대폰에 앱처럼 추가

  1. 휴대폰 브라우저로 이 사이트의 번역기를 엽니다.
  2. Android Chrome: 오른쪽 위 ⋮ → 홈 화면에 추가 (또는 '앱 설치')
    iPhone Safari: 공유 버튼 → 홈 화면에 추가
  3. 위쪽 [한→영] [영→한]으로 방향을 바꿉니다. [팝업 번역]을 켜고 글자를 길게 눌러 선택하면 사전·번역 팝업이 뜹니다.

이력·단어장 동기화 (GitHub)

  1. PC 번역기에서 [동기화] 버튼 → 저장소 ChangwooLee2/translator-data와 토큰 입력 → 저장하고 동기화
    토큰 만드는 법은 동기화 창 아래에 있습니다. 비공개 저장소 하나만 읽고 쓰는 토큰입니다.
  2. 다른 기기 연결: 동기화 창의 [다른 기기 연결] → 휴대폰으로 QR 촬영 (또는 링크 복사 후 다른 PC에서 열기)
  3. 이후에는 저장·단어장 추가·삭제할 때와 번역기 화면으로 돌아올 때 자동으로 맞춰집니다.

PC 설치판

  1. 받은 zip 파일의 압축을 모두 풉니다.
  2. 설치.bat을 더블클릭합니다.
    바탕화면과 시작 메뉴에 '오프라인 번역기'가 생깁니다. 설치 위치는 %LOCALAPPDATA%\OfflineTranslator입니다.
  3. 처음 한 번은 번역기 화면의 [번역 모델 다운로드]를 누릅니다 (위·아래 칸 각각, 이때만 인터넷 필요).
  4. 설치판도 [동기화]를 설정하면 웹·휴대폰과 같은 이력·단어장을 씁니다.
    설치판과 웹 버전은 브라우저 저장 공간이 서로 달라서, 동기화를 켜야 내용이 이어집니다.

단어·문장 팝업[팝업 번역]을 켜고 단어 더블클릭, Ctrl+클릭, 문장 드래그 (휴대폰: 길게 눌러 선택)
다른 프로그램에서PC 설치판 실행 중 글자 선택 후 Ctrl+Shift+Space

단어장팝업의 [단어장 추가], Ctrl+J로 보기, CSV로 내보내기

알아둘 점

  • 웹 버전은 한 번 열어 두면 인터넷 없이도 화면과 사전이 열립니다. 업데이트는 다시 접속하면 자동 반영됩니다.
  • 회사 방화벽이 github.io를 막으면 회사에서는 PC 설치판을 쓰세요. 동기화는 api.github.com 접속이 필요합니다.
  • 회사 PC에서 받은 zip이 보안 프로그램(DRM)으로 암호화되면 압축이 풀리지 않을 수 있습니다. 이때는 탐색기로 압축을 풀어 보세요.
  • 공용 PC에서는 사용 후 동기화 창의 [이 기기 연결 해제]를 누르세요.
