영어 데스크 (한↔영 번역 · 오프라인 사전 · 데일리 영어 학습)
==========================================================

Chrome에 내장된 번역 기능으로 PC 안에서만 번역합니다. 입력한 내용은 외부로 전송되지 않습니다.


■ 설치
  1. 압축을 모두 풉니다.
  2. 설치.bat 을 더블클릭합니다.
     → 바탕화면과 시작 메뉴에 '영어 데스크'가 생깁니다.
  3. 작업 표시줄에 고정: 바탕화면 아이콘 우클릭 → 추가 옵션 표시 → 작업 표시줄에 고정
  4. 처음 한 번은 번역기 화면의 [번역 모델 다운로드]를 누릅니다. (인터넷 필요, 위·아래 칸 각각)
     이후에는 인터넷 없이 동작합니다.

  * 필요: Windows 10/11, Chrome 138 이상
  * 새 버전으로 업데이트할 때도 설치.bat 을 다시 실행하면 됩니다. 이력과 단어장은 그대로 유지됩니다.


■ 기본 사용
  • 위 칸: 한국어 → 영어, 아래 칸: 영어 → 한국어. 입력하는 대로 바로 번역됩니다.
  • Ctrl+↑ / Ctrl+↓ : 위·아래 입력칸 이동
  • 경계선을 마우스로 끌어 칸 크기 조절, 더블클릭하면 원래대로. [↺ 크기 초기화]로 전체 초기화


■ 팝업 번역
  • 번역기 안: 위쪽 [팝업 번역]을 켠 뒤
      - 단어 더블클릭 또는 Ctrl+클릭 → 단어 번역 + 사전 뜻
      - 문장 드래그 → 문장 번역
  • 다른 프로그램(Outlook, 한글, PDF 등): 번역기를 켜 둔 상태에서
      글자 선택 → Ctrl+Shift+Space → 마우스 근처에 번역 창
  • 팝업의 [네이버 사전] 버튼: 인터넷 연결 시 네이버 사전 페이지 열기


■ 이력 (Ctrl+H)
  • 각 칸의 [저장] 또는 Ctrl+S 로 저장. 이력 창에서 클릭하면 다시 불러옴
  • [내보내기]/[가져오기]로 파일 백업·이동


■ 단어장 (Ctrl+J)
  • 팝업의 [단어장 추가] 또는 단어장 창 위 입력칸(Enter)으로 추가
  • 단어 클릭 → 사전 전체 내용 펼치기, 뜻 클릭 → 뜻 수정
  • [뜻 가리기]로 암기 확인 (마우스를 올리면 보임)
  • [내보내기]는 엑셀에서 열리는 CSV 파일


■ 다른 PC로 옮기기
  • 이력·단어장은 PC의 Chrome 안에 저장됩니다.
    기존 PC에서 [내보내기] → 새 PC에서 설치 후 [가져오기]


■ 제거
  • 제거.bat 을 더블클릭합니다. (이력·단어장은 먼저 [내보내기]로 보관하세요)


■ 사전 데이터 출처
  • Wiktionary (kaikki.org 추출본) — CC BY-SA 4.0
  • kengdic — MPL 2.0
  사전 뜻 중 '참고' 표시는 kengdic 데이터로, 일부 부정확할 수 있습니다.

■ 동기화 (회사 PC · 집 PC · 휴대폰)
  • 번역기 위쪽 [동기화] → 저장소와 토큰 입력 → 저장하고 동기화
  • 웹 버전: https://changwoolee2.github.io/Offline_Translator/
  • 설치판과 웹 버전은 저장 공간이 따로라서, 동기화를 켜야 같은 이력·단어장을 씁니다.

■ 영어 학습
  • 위쪽 [영어 학습] → 매일 약 30분 분량 (복습 · 표현 · 읽기 · 듣기 · 쓰기)
  • 끝나면 난이도·분량 피드백을 남기고 [학습 완료] → 다음 날 새벽에 피드백·작문 첨삭을 반영한 새 학습이 준비됩니다.
  • 지문에서 모르는 단어는 더블클릭 → [단어장 추가] (번역기 단어장과 같음)
  • [달력 · 이력]에서 지난 학습과 기록을 다시 볼 수 있습니다. (동기화 연결 필요)
